我們如何計算

  1. 從美國財政部確認 91282CHC8 的票息、發行與到期日；其每半年支付一次票息。
  2. 以 FRED DGS10 的每日十年期公債殖利率，代理該債的到期殖利率，折現剩餘現金流。
  3. 用現金流現值加權，計算麥考利存續期間，再換算修正存續期間。
  4. 按日期讀取 FRED 的期限溢酬與 DEXJPUS 匯率；比較同一觀察窗的端點變化。
P = Σ CFₜ / (1 + y/2)^(2t)
Dₘₒd = [Σ t · PV(CFₜ) / P] / (1 + y/2)

t 以年計；半年付息；面額 100；每期票息 1.6875。DGS10 並非此 CUSIP 的實際成交殖利率，因此存續期間是估算值。

資料來源：美國財政部拍賣結果；FRED DGS10、THREEFYTP10、DEXJPUS。圖表內嵌的 FRED 資料擷取於 2026-11-11；各系列最新觀測日期可能不同。開啟時嘗試更新。DGS10、THREEFYTP10 與 DEXJPUS 均為公開領域資料，請依來源註明出處。
